# Simple Line Editor in C

## Team Members

- Nithin Uttarkar

## Features Implemented

- Insert a line
- Delete a line
- Display the document

## Description

This project is a simple command-line line editor developed using the C programming language.

The program allows users to:

- Insert a new line at a specified position
- Delete a line
- Display all lines with line numbers

The document is stored in memory using an array of strings.

## Requirements

- GCC Compiler
- Visual Studio Code

## How to Compile

Open the terminal in the project folder and run:

```bash
gcc lineeditor.c -o lineeditor

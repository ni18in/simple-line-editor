# Simple Line Editor - Help

## 1. Insert Line

Adds a new line at a specified line number.

### Usage

1. Select option 1.
2. Enter the line number.
3. Enter the text.

### Example

Enter line number to insert: 1

Enter text: Hello World


## 2. Delete Line

Deletes a line from the document.

### Usage

1. Select option 2.
2. Enter the line number to delete.

### Example

Enter line number to delete: 2


## 3. Display Document

Displays all the lines in the document along with their line numbers.

### Usage

Select option 3.


## 4. Exit

Closes the Simple Line Editor.

### Usage

Select option 4.
